# Synapse

A responsive SYNAPSE website built with React, Tailwind CSS, and React Router.

## Run locally

```sh
cd frontend
npm install
npm run dev
```

## Pages

- `/` — Home / landing page
- `/login` — Login page
- `/signup` — Sign-up page
- `/about` — About Synapse
- `/features` — Platform features

Audience navigation items remain placeholders for future pages.

## Frontend structure

```text
frontend/

  src/

      LoginPage.jsx
```
